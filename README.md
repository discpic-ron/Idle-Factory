# Idle-Factory

Idle Sweatshop is a scalable resource-automation simulator where players can expand their production lines, hire workers, and unlock upgrades along the way to increase profits while under regulatory pressure. To optimize long-term operations, players use strategic planning in both labor and machine efficiency.
